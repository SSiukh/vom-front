# VOM SYSTEMS

> Система використовується для створення замовлень, обліку витрат та товарів, перегляду аналітичної статистики та автостворення ЕН "Нова Пошта".

## ⚙️ Глобальні компоненти (layout за замовчуванням)

### `Хедер`

> Стандартний хедер адміністративної панелі, ненав'язливий та простий. Відображає логотип системи та базові авторизаційні параметри

**Параметри**

| Параметр | Тип    | Призначення                                                                                       |
| -------- | ------ | ------------------------------------------------------------------------------------------------- |
| Логотип  | Текст  | Візуально відображає систему                                                                      |
| Логін    | Текст  | Відображає під яким користувачем було зайдено, відображається лише для авторизованих користувачів |
| Вихід    | Кнопка | Кнопка у вигляді іконки виходу, відображається лише для авторизованих користувачів                |

### `Сторінка налаштування двохфакторної авторизації`

> Сторінка представляє собою можливість типового налаштування 2FA після входу. Після логіну, поки не налаштована двохфакторна авторизація - всі інші вкладки недоступні.

**Параметри**

| Параметр             | Тип    | Призначення                                                                                  |
| -------------------- | ------ | ---------------------------------------------------------------------------------------------------- |
| QR-код               | Image  | Відображення QR-коду для підключення Google Authenticator                                    |
| Секретний ключ       | Text   | Відображення секретного ключа для ручного додавання облікового запису в Google Authenticator |
| Код підтвердження    | Input  | Введення 6-значного коду з Google Authenticator для підтвердження налаштування 2FA           |
| Кнопка «Підтвердити» | Button | Перевірка введеного коду та завершення налаштування 2FA                                      |
| Коди відновлення     | List   | Відображення резервних кодів для відновлення доступу до облікового запису                    |
| Кнопка «Скопіювати»  | Button | Копіювання кодів відновлення до буфера обміну                                                |
| Статус 2FA           | Status | Відображення поточного статусу двофакторної автентифікації                                   |

### `Сторінка відправники`

> Сторінка, яка відображає перелік внесених відправників Нової Пошти. Тут в переліку можливо вибрати відправника, від якого будуть здійснюватись відправки. Також є можливість перейти до сторінки внесення відправника

**Параметри**

| Параметр           | Тип     | Призначення                                                                                             |
| ------------------ | ------- | ------------------------------------------------------------------------------------------------------- |
| Внести відправника | Кнопка  | Перехід на сторінку внесення відправника                                                                |
| Список             | Таблиця | Відображення переліку відправників. Заголовки: ПІБ, Номер телефону, Статус, Дії                         |
| Пагінація          | Елемент | Можливість розділяти та переходити на сторінку. Відображається лише за наявності більше 10 відправників |

**Параметри елемента списку**

| Параметр       | Тип     | Призначення                                                                                                       |
| -------------- | ------- | ----------------------------------------------------------------------------------------------------------------- |
| ПІБ            | Рядок   | Відображає ПІБ відправника                                                                                        |
| Номер телефону | Рядок   | Відображає номер телефону відправника                                                                             |
| Активний       | Чекбокс | Можливість обрати відправника. Наявна валідація, що можливо обрати лише одного відправника зі списку              |
| Оновити дані   | Кнопка  | При натисканні оновлюються дані відправника шляхом запиту до нової пошти                                          |
| Видалити       | Кнопка  | При натисканні відображається додаткове підтверджуюче вікно. Після підтвердження відправник видаляється з системи |
